# 固定指南问答能力约束

这是应用维护文档，不是让运行时自动执行的 Codex Skill；实际模型指令由 `prompts/` 提供。

- 依据只来自 `data/guide.json` 的固定完整条目。候选标题只用于定位。
- `search_entries(query)` 返回候选标题；`get_entry(guide_id)` 返回完整正文、成本、收益、证据、来源及备注。
- 两个工具由 Python 应用绑定本轮用户和请求版本，模型不能自行选择用户、运行编号、文件或网址。
- 引用前必须完成本轮全文回读；无法完整读取是技术失败，不应伪装成“指南没有覆盖”。
- 模型仅选择指南 ID 和实际参考的记忆 ID。应用核对后按来源字段显示内容，不展示模型创造的建议正文。
- 当前输入优先于长期摘要。不推断诊断、不把提供建议认定为已执行或已解决。
- 每轮答复完成来源校验后，独立摘要调用记录明确状态、问题和真实咨询过的指南。首页回访不保存对话摘要。
- 首页只选择有效且未确认解决的问题，应用生成进展问题与是否继续咨询指南的问题，不显示指南正文。

检索目前为中文二元词匹配基线，没有向量检索或重排。该约束不表示已完成所有场景的答案质量评测。
