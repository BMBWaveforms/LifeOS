# 团队讲解材料

这份材料说明当前 Python 独立版的产品循环、技术模块、数据与提示词边界，以及上线前待补工作。保留的 Dify 版本是项目历史版本。

## 从哪里开始

- **苟活项目架构与流程说明.pdf**：12 页，适合直接转发和投屏讲解。
- **苟活项目架构与流程说明.html**：离线打开，有目录导航和四张内嵌图。
- **苟活项目架构与流程说明.md**：可编辑正文，包含 Mermaid 流程图代码。
- **图示/**：整体架构、问答流程、记忆更新、首页回访；每张提供 PNG、SVG 和 Mermaid 源文件。

给团队讲解时，先讲用户提问到下次回访的业务循环，再展示四张图，最后按文档第 11 节完成一次十分钟讲解。第 12 节提供常见问题回答。

正文和图表可离线阅读。附录中的代码链接适用于项目目录内的原件；独立资料包不包含应用源码、模型凭据、账号密码或用户记忆。

## 如何维护

修改 Markdown 正文，并在 `维护/生成讲解材料.py` 的 `graphs` 中修改流程节点和连线。脚本会重新生成 SVG、PNG、Mermaid、HTML 和 PDF，并将图定义同步到 Markdown，因此不要只改自动生成的图块。正文不在图块内的内容会保留。

渲染工具依赖见 `维护/requirements.txt`，与应用运行环境独立。当前字体路径为 macOS 的 `/System/Library/Fonts/Supplemental/Arial Unicode.ttf`；其他系统请改为支持中文的 TTF 字体。

在当前电脑重建：

```sh
/Users/sylas/Desktop/苟活/.document-tools/bin/python /Users/sylas/Desktop/苟活/python-standalone/docs/团队讲解/维护/生成讲解材料.py
```

重新生成后检查 `维护/预览/` 下的 PDF 页面，确认中文、图表和分页正常，再交付。预览图片不纳入资料包。
