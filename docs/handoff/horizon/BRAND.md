# LEVO 品牌替换

用户提供《LEVO 品牌名》中的原始Logo和品牌组合：英文品牌 LEVO；中文品牌“人生性价比指南”；英文标语“Make Life Worth More.”；中文表达“让每一份投入，都更值得。”。

首页使用中文标语，关于面板保留中英文表达；首页/侧栏Logo、助手署名、浏览器标题与图标、分享卡片及下载文件名同步替换。场景标题及描述保留场景内容。

assets/mark.svg 是包裹原PNG的自包含SVG容器，仅通过视窗去掉素材外围留白，不生成或重绘图案。SVG使用原图亮度遮罩显示标志、消除黑色底，网页用黑白反相适配深浅底色，分享卡片在同源画布中绘制相同素材，无远程图片依赖。现有静态预览资产白名单已包含mark.svg。

LEVO是产品展示名；Horizon目录、LifeOS仓库名、历史存储键与接口身份保持兼容，旧记录不迁移或清空。没有修改后端与Agent能力。

本轮品牌更新随正式前端展示层交接，接口身份与原有浏览器记录保持兼容。

验收：1440×900与1280×720的首页、侧栏、助手署名、分享PNG均通过；PNG为1080×2805，导出正常且无脚本异常。49项独立前端测试通过。合成验收结果见QA记录，不含个人对话。
