# 功能差异与边界

状态含义：**前端完成**指界面与本地行为已实现；**演示完成**指固定数据流程；**现接口复用**指已按基线 API 编写适配，但本交付未用真实账号/模型实测；**待后端**不代表存在对应接口。

| 功能 | Horizon 当前实现 | 现有后端 / 接手差异 |
|---|---|---|
| 视频 Landing | 前端完成：15 个生活场景，黑白，场景主标题及说明随视频更新，左上品牌区包含Logo与固定产品slogan，场景标题/说明在右侧，输入区位于左下，编号紧邻场景标题，切换/拖动，无暂停按钮 | 不需要 Agent；样片可替换，授权来源见 assets/media-sources.json |
| 三种进入方式 | 前端完成：视频按当前场景直接发问；输入发送；输入框下方“直接进入 →”不发问、与框内文字对齐 | 原产品情境先填入再发送；Horizon 明确采用直接发问，不能恢复成二次确认 |
| 首页快捷入口 | 首页回访卡片已移除；保留按场景发问、自由输入、“直接进入 →” | 前端不再为首页调用 getHome/mode=home，后端接口保留；记忆列表的继续聊仍显式关联原对话/摘要 |
| 基础多轮对话 | 多轮用户/助手排版、状态、独立草稿、serverId 续接 | 现接口复用 conversation_id；后端SDK上下文有隔离持久化，受有效期/revision/配置绑定影响，不能等同产品完整历史 |
| 回答排版 | 普通回答、追问和流式容器支持Markdown标题、加粗、斜体、列表、引用及代码；演示项目含完整示例 | result.message/clarification/markdown或text_delta携带Markdown文本即可；不猜测普通文本重点、不修改后端提示词。仅允许DOM白名单，原始HTML按文本显示 |
| 流式容器 | 演示分片、停止、失败、部分文本、刷新中断、重试、长阅读不抢滚动、回到最新 | 待后端公开流式协议；现 `/api/run` 是最终 JSON，容器不会伪装真实流式 |
| 停止/重试 | 前端完成：AbortSignal、忽略迟到分片、保留输入/部分文本；明确提示结果可能已在后台产生 | 现接口无服务端取消或幂等请求查询。停止等待不代表取消服务端，也不保证重试不重复摘要 |
| 追问 | 前端完成：问题、可选快捷选项、暂不补充、自由输入；演示有选项流程 | 现后端输出 clarification 字符串，可显示。clarification_options / allow_skip 是建议扩展，未实现；前端不会凭空给真实答复加选项 |
| 最近历史 | 前端完成：最多6段普通对话，分组固定“最近对话”；项目演示单列；14px标题/12px时间与轮数区分同名；全量数据保留 | 当前后端没有产品历史列表 API；不能调用工作台会话接口冒充产品历史 |
| 对话删除 | 当前仅删除本机展示、保留已存记忆 | 上游已提供`/api/conversation-action`撤销SDK会话，Horizon尚未连接；接手需统一撤销/保留语义 |
| 对话排序 | 直接拖动对话，移动8px后拖起/让位/落下；仅同组调整，支持Alt+上下键、Escape取消；新对话在前 | 点击打开不改变顺序，默认按实际消息时间排列；手动顺序只保存ID，随演示localStorage/真实sessionStorage按账号隔离；没有服务端排序接口，不要求Agent推断排序 |
| 全部历史 | 前端完成：入口紧跟最后一条最近对话；全文搜索、命中片段/定位、日期、轮数、重命名、删除 | 演示 localStorage，真实 sessionStorage 按账号分区；不是服务端永久历史管理 |
| 项目分组 | 3段“搬家计划”演示对话，静态细线与缩进区分层级，文字邻近位移，无块状选中/悬停，平滑展开/收起，无文件夹/文件管理 | 仅示例；没有创建/编辑真实项目的功能或 API，也不共享项目级 Agent 上下文 |
| 当前对话理解 | 只读、引用原话、跳回对应轮次；从显式用户文本提取的保守前端规则 | 不是 AI 推理流，也不是长期记忆。后端已有任务 understanding，含 intent/explicit_facts/unknowns/scope，尚未映射；二者语义不同，不可盲目覆盖 |
| 自动记忆 | 演示始终开启，UI 没有关闭/编辑；会话内容与保存状态分别展示 | **P0 策略冲突**：后端 profiles.enabled 默认 false，settings / correct_summary 仍开放；仅删按钮不能约束 API。迁移须保留老数据并制定后端策略 |
| 记忆内容 | 演示保存原问题，后续产生新条目、旧条目标 superseded | 真实后端保存经证据验证的模型摘要，不等于原文；保留真实摘要来源/状态，不把演示原文替换过去 |
| 记忆列表 | 搜索/当前有效/历史筛选，查看，只删/全删，取消或 Escape 保留筛选位置 | 现接口复用 memories/effective。真实后端删除还会清理账号全部指南反馈，当前确认文案已说明，后端可进一步细化 |
| 从记忆继续聊 | 有本机来源对话则回来源对话；来源已删则新建，带入准确摘要并自动发送；已有恢复对话复用 | 现后端不返回持久化 source_conversation_id。本机可通过响应 summary.memory_id 关联；跨浏览器无原聊天只能从摘要恢复。需定义受账号授权的持久化来源关系 |
| 删除记忆后的回访 | 当前浏览器清除失效 followupId，刷新回访，不用无关记忆替代 | 后端 revision 校验保持；跨标签/其他设备失效通知待接口，不会靠UI保证全局同步 |
| 指南卡片 | 完整原文、成本/收益/证据、记忆引用；进入视野620ms渐显，已见卡片不重播；真实数据应只收后端验证后的 card | 沿用 get_entry 全文回读与 finalize 校验；不得直接展示模型编造的指南或跳过证据校验 |
| 指南详情 | 内部阅读弹层、过渡、滚动、完整字段，无跳 GitHub 的条目链接 | 后端已有 `/api/guide-entry?guide_id=`；当前卡片带完整字段可直接读，不必每次新请求。指南总体来源许可保留 |
| 决策账本 | 按决策问句及指南字段触发，打开后自动按阅读顺序逐词清晰展开，不随滚动倒播，无“直接看全文”入口；证据等级/投入标签/出处与范围、完整可见后盖章；144px环形印章与双层淡涟漪叠压全宽内容，无独立结尾文案区；通勤时间计算。无底部重播/继续聊入口 | 前端完成；不是独立 Agent 任务，不会替用户下最终结论。没有指南字段时不伪造财务/时间数据 |
| 分享指南 | 前端完成：PNG预览、下载，支持时调用系统文件分享；取消/失败反馈 | 无分享服务器、不生成公开链接、不自动发送朋友；只含指南白名单字段与归属，不含问题/记忆/用户信息 |
| 账号与模式 | 交互演示默认；真实账号登录/退出 UI，按账号隔离原文；静态预览不能切真实 | 现接口复用 cookie 会话。无注册/重置密码/SSO，团队账号由后端管理，模型密钥不得进入浏览器 |
| 模型与执行层 | 前端只发现健康状态，不管理模型 | 后端已统一SDK并支持隔离会话恢复/受控压缩，不是缺失；不能误写成“后端尚无模型服务”。Horizon 未用真实模型做端到端验收 |
| 提示词/评测工作台 | 不在新版产品页面复刻 | 现后端/原工作台已实现，保留独立入口；导入、编辑、评测、激活遵从原 registry，不复制旧 prompts 覆盖 |
| 专业意见提示 | 输入框下统一免责声明 | 保持固定指南边界，不能通过文案暗示医疗/法律/财务结论已获担保 |
| 关于/联系我 | 关于可读；联系我有样式、无真实地址（产品要求） | 占位不是漏接 API；后续由负责人提供联系方式 |
| 桌面布局/动效 | 黑白、有限字号层级、侧栏与正文标题同步、减少动效设置、键盘可达 | 不做手机布局（产品要求）；不能把手机适配列为本轮阻塞 |
| 附件/语音/联网/工具进度/重新生成 | 未实现，未在本版产品中承诺 | 原业务仅两种只读指南工具。扩展须单独定义产品与权限，不自行放出未经校验的工具执行事件 |

演示已实现的幂等 requestId、本地记忆/历史与模拟流不能证明真实后端具备同等能力。正式能力声明以 API、服务端测试与真实验收为准。

最新账本呈现：正文自动从上往下渐显；两处来源证据等级恢复简洁字母样式并保留限定说明；印章外环重复“投入 · 收益 · 证据”、中央LEVO，直接叠在全宽正文上，完整进入视野后落章。“直接看全文”已移除。细节见LEDGER_READING.md。
