# SDK 执行层、连续会话与测试台

问答、自动摘要、首页回访和评测语义判定统一使用 Claude Agent SDK 0.2.166，通过 DeepSeek 的 Anthropic 兼容入口调用模型。Python / FastAPI 保留身份、重要记忆、问题状态、来源校验与事务；不再提供 NativeExecutor 或执行层切换，也没有失败后自动回退。

完整产品入口是团队最新 Horizon 页面，`/workbench.html` 是内部自由测试、批量评测和提示词工具。产品与测试数据隔离；GitHub Pages 仍是静态模拟，不包含真实测试台。

## 谁负责什么

| 部分 | 职责 |
|---|---|
| `backend/model.py` | 每轮提供当前业务状态，组合提示词；校验答案、保存重要事实和问题进展，再授权SDK历史恢复 |
| `backend/executors.py` | 唯一聊天执行层；SDK工具循环、指定会话恢复、压缩配置及白名单观测 |
| `backend/sdk_sessions.py` | 用户/会话隔离、私有transcript、提交标记、版本失效、过期与清理 |
| `backend/completion.py` | 摘要/首页/判定的无工具SDK临时任务，不恢复聊天历史，结束即清理目录 |
| `backend/tools.py` / `store.py` | 两个只读指南工具；本轮全文回读、账号、记忆revision和来源正文校验 |
| `backend/workbench.py` / `evaluation.py` | 隔离测试、持久结果、版本化评测与提示词方案A/B |

五环节是观察和判定维度，不是五个独立Agent。前三个提示词模块合成聊天指令；摘要和首页各自是独立任务，评测语义判定再运行一个隔离任务。模型私有思维链不作为业务数据或评测证据。

## 连续聊天

首轮发送前确定随机应用 `conversation_id`，SDK在对应隔离目录开始会话。应用ID保持稳定，SDK原生历史重建通过context_reset标识。下一轮传回应用ID，后端检查：用户、最终记忆revision、提示词、工具、指南快照、模型配置、压缩策略和有效期均匹配，且本地transcript完整、上一轮已提交，才向SDK传指定 `resume`。不使用“最近会话”恢复，不由Python重放最近六轮历史。

每轮仍创建新的 `run_id` 和 `GuideTools`。SDK历史里的指南正文只是背景，不能代替本轮 `get_entry` 完整读取。后端每轮重新注入有效记忆、进展、设置和候选标题；历史中同名字段不具备本轮权威性。

SDK执行成功后，Python继续检查结果、整理摘要并做最终revision检查；这些完成后才提交恢复标记。自动摘要本身会提升revision，提交标记记录提升后的值，正常续聊不会因此每轮重置。模型失败、工具失败、来源失败、进程中断或并发记忆管理造成的旧结果，均不能恢复为下一轮上下文。

删除、纠正、清空、开关和反馈等明确管理操作会立即撤销并清理该用户SDK历史。事实在会话前或本轮执行中到期，旧历史/结果也失效。模型、提示词、工具、指南或压缩配置变化会使不兼容会话在下次使用时重建。

## 压缩与保留

默认开启SDK自动压缩，提前阈值设为SDK计算窗口的60%。压缩要求优先保留用户明确事实、未解决事项、已做动作与真实咨询过的指南编号；区分用户事实和助手推测；旧run_id、memory_ids和回读权限不沿用。指令是尽力要求，不保证压缩无损。关键事实和问题状态从SQLite重新提供，并由后端校验。

`PreCompact`只记录触发类型，`compact_boundary`只计数；不把原始压缩摘要输出到评测。服务层支持受控 `ExecutionRequest.compact_context=True`，在恢复的会话中先执行带固定保留要求的 `/compact`，再运行本轮任务；它不是允许前端执行任意命令的API。

| 配置 | 默认 | 含义 |
|---|---|---|
| `AGENT_SDK_AUTO_COMPACT` | `true` | false关闭自动压缩，手动压缩仍可用；操作者需处理窗口上限 |
| `AGENT_SDK_COMPACT_PCT` | `60` | 1—100，CLI只允许提前，不能用高值抬高默认触发点；不是实际模型硬token预算 |
| `AGENT_SDK_CONTEXT_USAGE` | `false` | 开启时限时尝试上下文统计；兼容接口不支持时unknown，不能写0 |
| `AGENT_SDK_SESSION_TTL_SECONDS` | `604800` | 闲置7天后禁止恢复；下次访问该用户会话时清理文件 |
| `AGENT_SDK_MAX_SESSIONS` | `30` | 每用户保留上限，开始后续会话时清理较旧记录 |

没有后台定时删除线程，也没有承诺固定比例压缩、逐条精确保留或无限上下文。当前DeepSeek接口是否正确支持自动触发和token统计，必须用真实锁定版本另行验收；不能从配置存在或mock通过推断效果。

## 私有历史与重要记忆

SDK恢复文件位于运行卷 `agent-runtime/<owner_hash>/sdk-sessions/` 下，每个对话独立cwd和config；目录0700、文件0600。只保存恢复所需的原生记录，不进入Git、API、评测JSON或静态预览。工具仍为空的内置清单、`setting_sources=[]`；关闭自动记忆，不加载个人配置或CLAUDE.md，不开放Bash、文件、Web或子Agent。

产品自动启用长期记忆，用户可删除来源或主题；隔离评测的“关闭长期记忆”会删除之前的SDK历史并停止长期摘要读写，关闭后的测试聊天仍有本次会话历史并按上述期限保留。长期摘要和当前会话历史是不同的数据用途。删除长期摘要不会删除已经导出的外部副本。

产品聊天展示目前仍只在当前页面。刷新开始新对话，未新增完整历史列表或跨设备恢复UI；SQLite摘要仍可从回访进入。后台和测试台只要持有有效应用conversation_id，重启后可恢复已提交SDK会话；不能仅保存session_id而丢失transcript。

摘要、首页和判定使用独立临时目录，不恢复、不混入聊天历史、无工具；任务成功/失败/超时后都清理临时目录。

## 模型与部署

SDK包内包含Claude Code CLI，不要求宿主机另装Claude Code。私有模型JSON仍兼容原Key/model/base_url字段；所有实际调用使用 `AGENT_SDK_BASE_URL`。DeepSeek缺省映射为 `https://api.deepseek.com/anthropic`，其他提供者必须显式配置真实兼容地址。旧 `AGENT_RUNTIME` 不再改变执行层，HTTP请求显式native会被拒绝。

沿用原 `.env.compose`、Compose项目名和数据卷执行 `up -d --build`；不删卷、不重设身份。代码回退使用已验证提交，不再靠native回切。问答最多7次工具轮转、24次工具调用和180秒；摘要/首页/判定独立受控超时。SDK的USD估算不作为DeepSeek实际费用。

## 测试台与历史兼容

自由测试只提供SDK、输入、连续会话、工具轨迹和运行记录。旧native结果仍可查看/下载，但不允许续接。新会话清空当前续聊关联，保留历史结果。

批量A/B选择两份提示词组合，两份都通过SDK，保持用例、提示词和判定版本快照。旧native批次保持可读/可导出，不能按原native快照重跑，应创建新的SDK方案；禁止静默换执行层后声称是原快照结果。

测试会话保存最新成功结果的应用conversation_id。重启后恢复通过SDK私有历史完成，不再重放Python问答数组。失败轮次保留安全错误及工具证据，不保留可恢复的失败SDK历史。

| 接口 | 用途 |
|---|---|
| GET `/api/runtimes` | 唯一SDK、安装状态、包版本；安装不证明凭据/余额可用 |
| POST `/api/test-sessions` | 创建隔离测试会话；runtime可省略或为claude-sdk |
| POST `/api/test-run` | 运行或续接自己的SDK测试会话 |
| GET `/api/test-runs` / `{id}` | 本账号历史概要和完整安全记录 |
| POST `/api/run` | 产品chat/home；显式native请求拒绝 |

参考：[SDK会话](https://code.claude.com/docs/en/agent-sdk/sessions)、[压缩](https://code.claude.com/docs/en/agent-sdk/agent-loop#automatic-compaction)、[环境变量](https://code.claude.com/docs/en/env-vars)、[DeepSeek接入](https://api-docs.deepseek.com/guides/coding_agents/)。固定指南引用与许可不变。执行完成和质量通过分开验收。

产品支持 POST `/api/conversation-action`：`{action:"delete",conversation_id}`，仅删除当前用户指定SDK会话（含在途恢复授权），幂等；长期摘要单独管理。页面删除确认等服务端成功后才移除本页对话，失败可重试。

对话删除先写私有哈希撤销标记（仅时间，不含正文），再删除原生历史；标记跨重启保留，普通记忆清理不会擦掉。删除先于模型开始或发生在模型/摘要执行中都会阻止提交。后台请求可能继续执行，迟到写入在任务退出后清理；删除不承诺立即终止模型进程。
