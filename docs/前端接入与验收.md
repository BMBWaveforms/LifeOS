## 产品行为与真实边界

- 首页使用 15 个本地视频场景，视频、封面、标题、输入提示和场景提问由 `landing-scenes.mjs` 配对。场景点击直接发问；输入框下的“直接进入”不发问，进入当前或空白对话并保留已有草稿。历史支持搜索、重命名、直接拖动与 Alt + 上下键排序；只读理解面板、内置指南阅读及分享卡片保留。项目分组仍是明确标识的演示，未增加项目管理后端。
- 按本轮首页设计移除回访卡片、暂停按钮及产品前端对 `getHome()` 的调用。后台 `mode=home` 接口、首页回访提示词和评测能力保留；用户仍可从“我的记忆”按主题或来源继续聊。没有首页卡片不等于删除长期记忆，也不代表已有定时通知能力。
- `/api/run` 继续使用最新 SDK 服务；只允许 `search_entries`、`get_entry`，指南必须在本轮完整读取，正文由后端生成。服务端仅返回最终 JSON；演示分片与展示动画不等于真实流式接口。理解面板只使用可观察的用户原话和任务标签，不展示隐藏推理。
- 普通答复、追问及演示分片使用 `answer-markdown.mjs` 的 DOM 渲染子集，支持标题、强调、列表、引用、代码和受限链接。HTML 保持文本，Markdown 图片不加载为图片；链接仅允许 HTTP、HTTPS、mailto 和受限页内锚点，外链使用 `noopener noreferrer`。不把未经校验的模型或 SDK 私有输出接进页面。
- 产品账号自动启用记忆。部署启动迁移旧关闭状态并提升 revision，使旧 SDK 会话不能按旧设置恢复；保留已有账号、来源与记录。前端展示“主题摘要 → 来源原话/时间”，可删除单条或整个主题；产品 API 拒绝开关、手动纠正和手动写入。隔离评测仍可模拟这些情境。
- 来源原话会保存在后端并用于长期整理。摘要是派生缓存；删除后清理相关浏览器回访引用、主题缓存和 SDK 恢复权限。删除成功而后续读取失败时，不显示旧缓存，也不把成功删除报告成未删除。
- 对话历史存在当前浏览器、按账号隔离的 sessionStorage 中；没有跨设备历史列表或完整会话云同步。后端 `conversation_id` 仅授权该账号在有效期内续接 SDK。删除对话同时撤销后端 SDK 会话。
- 记忆读取代次、登录/退出的迟到响应保护及删除后的本机失效处理继续保留。当前页面切换模式或账号后，旧请求不能恢复另一账号的记忆面板或覆盖新身份；刷新失败不能重新显示已删除来源的缓存。
- 分享卡片只包含指南内容，不包含个人原话、记忆或理解面板。指南署名、许可与媒体来源登记保留在 `frontend/assets/`。媒体的素材登记不齐：新增用户提供视频在 `media-sources.json` 中明确标为“未附授权元数据”。不得根据文件名或画面推断作者、许可或来源链接，也不能把全部素材宣称为已完成授权核验；后续只补录有凭据的信息。
- `/workbench.html` 保留单环节测试、整体测试和提示词管理。单环节仍是固定上游输入的隔离实验，检索环节实际使用两个只读工具，其他环节无工具；产品记忆和 SDK 会话不进入测试。生产中理解/检索/回复仍合为一次 SDK 循环，记忆/摘要合为一次整理任务，不因界面更新拆成七个生产阶段。

## 接口映射

| 功能 | 接口 |
|---|---|
| 登录与身份 | POST `/api/login`、GET `/api/me`、POST `/api/logout`，HttpOnly Cookie |
| 真实问答 | POST `/api/run`，`mode=chat`，传 `query/conversation_id/followup_memory_id` |
| 后台首页回访 | POST `/api/run`，`mode=home`；接口与评测保留，本轮根产品前端不调用 |
| 主题/来源 | GET `/api/memories`，`policy=automatic_delete_only`、`enabled=true`、`topics[]/sources[]/excerpts[]` |
| 删除来源/主题/全部 | POST `/api/memory-action`，`action=delete|delete_topic|clear`，对应 `id` |
| 指南反馈 | POST `/api/memory-action`，`action=feedback`，服务端校验 ID/归属 |
| 删除 SDK 对话 | POST `/api/conversation-action`，`action=delete,conversation_id` |
| 指南详情 | GET `/api/guide-entry?guide_id=...` |
| 单环节提示词测试 | GET `/api/prompt-tests/catalog`、GET/POST `/api/prompt-tests`、GET `/api/prompt-tests/{id}`；结果按账号隔离 |
| 整体评测与提示词管理 | 既有 `/api/eval/*`、`/api/prompts/*` 及隔离交互测试保持独立；详见[评测工作台](评测工作台.md) |

## 启动和静态预览

完整应用使用原 Compose 或 `scripts/frontend_server.py` 的同源代理，不增加新服务。`.mjs` 必须返回 JavaScript MIME，视频和分享所需的 CSP 由随仓库 Nginx 配置提供。开发端口更换时同步配置 `ALLOWED_ORIGINS`。

`scripts/build_preview.py` 使用同一产品代码的白名单构建，固定 `real_api_enabled=false`，不复制测试台、账号、模型配置或数据库。DemoService 只使用虚构浏览器记录；静态 Pages 的问答和摘要不能作为模型验收。运行 `python scripts/build_preview.py` 后可用普通静态 HTTP 服务查看 `.preview-site/`。
