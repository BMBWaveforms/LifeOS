# 正式前端接入与验收

2026-10-15 接入合伙人 [lrj813/LifeOS](https://github.com/lrj813/LifeOS) 的页面、样式与素材，来源提交为 `7d89e4b18bfaa27d49235826d740e50e200b1aff`。`frontend/index.html` 是唯一产品入口；原问答测试页不再提供产品首页，`frontend/workbench.html` 继续保留为内部自由测试、批量评测与提示词管理工具。

## 当前产品路径

1. 首页的八张情境卡片是固定入口，定义在 `frontend/scenes.js`；不根据个人记忆动态排序。点击后带入话题和指南编号，用户确认提交后再调用问答接口。
2. 真实问答通过同源 `/api/run` 执行，后端默认使用 Claude Agent SDK 调度 DeepSeek。仅开放两个只读指南工具；后端仍校验本轮完整指南读取、来源和记忆版本。
3. 回答展示后端正文与相关指南。指南详情读取 `/api/guide-entry`，展示正文、成本、收益、证据、限制及原文链接。固定卡片和模型回答都不能代替适用条件核对。
4. 个人档案提供自动摘要开关，新账号默认关闭。开启后，问答在后端完成摘要处理再返回；页面分别呈现答复和摘要保存状态，保存失败不能显示为已保存。关闭后停止长期记忆读写，已存摘要仍可查看或删除。
5. 首页单独显示问题回访，包含进展问题和继续咨询入口。继续聊使用当前摘要 ID；后端更新摘要后返回新的 `summary.memory_id`，前端替换关联 ID，避免下一轮发送已被替代的记录。删除记忆后清理当前关联并刷新回访。

## 接口契约

| 操作 | 接口及字段 |
|---|---|
| 登录与用户 | `/api/login`、`/api/me`、`/api/logout`；用户来自登录 Cookie |
| 固定情境 | `scenes.js`：`id/title/guide_id/guide_title/draft/image/alt`；前端静态配置 |
| 提问 | POST `/api/run`：`mode=chat`、`query`、`conversation_id`、`followup_memory_id`，固定情境可带 `guide_id` |
| 问答结果 | `conversation_id`、`result.message/cards/status`、`summary.saved/message/memory_id`；错误按失败呈现 |
| 指南详情 | GET `/api/guide-entry?guide_id=...`；`guide_id/title/fields/source_url/source_locator` |
| 摘要列表 | GET `/api/memories`：`enabled`、`effective[]`；记录含 `id/problem` 等摘要字段 |
| 摘要开关与删除 | POST `/api/memory-action`：`{action:"settings",enabled:...}` 或 `{action:"delete",id:...}` |
| 问题回访 | POST `/api/run`：`mode=home`；`result.followups[]` 包含 `memory_id/topic/progress_question/guide_question` |

选择固定指南只是给问答提供咨询方向，后端仍要求工具完整读取；不能直接把前端卡片当作本轮已读来源。

## 启动与部署

沿用 [README](../README.md) 和 [部署验收手册](Agent部署与验收.md)。Docker、本地脚本和直接 Python 启动在没有覆盖配置时都默认 `claude-sdk`。SDK 使用 DeepSeek 的 Anthropic 兼容入口；摘要和首页回访继续使用已有 Chat Completions 调用。模型 Key 只保留在私有配置，不进入前端或预览；SDK 失败明确报错，不自动回退。

正式前端和 `/api` 必须同源：Docker 由 Nginx 统一提供，本地开发由 `scripts/frontend_server.py` 代理。不要直接用文件路径或 GitHub Pages 调真实后端，也不要将后端私有端口直接暴露到公网。

聊天历史目前仅保留在当前页面；刷新或退出会清除本页对话。后端长期摘要不因此删除，用户可从回访或个人记忆继续。当前范围不包含服务端历史列表、跨设备恢复、流式回复、重新生成或动态个人推荐。

## 静态演示与素材

`scripts/build_preview.py` 按白名单复制产品页面、固定情境、样式、素材和八条指南示例，再注入 `preview/mock-service.js` 与 `preview/adapter.js` 的独立 `PreviewProduct`。不拦截真实请求，不复制后端、测试工作台、真实账号、模型配置、数据库或运行记录。模拟记录只在本页内存中存在，刷新即重置；演示账号 Alice/Bob 和口令 `preview` 均为虚构。

预览徽标和问答均注明固定场景模拟。静态页没有真实模型或后端 API，模拟摘要及回访不能作为真实 AI 验收。页面保留架构说明入口、指南来源和 CC BY 4.0；打包 Noto Serif SC 字体时一并保留 `frontend/assets/fonts/OFL.txt`。
