## 变更与迁移

- 产品：保留团队最新视频场景、对话侧栏/排序、理解面板、指南阅读和分享；接入主题摘要、原话来源、单条/整主题删除。删除对话接后端 SDK 撤销；账号切换后的迟到登录、记忆/回访响应会被丢弃。
- 产品策略：新版本启动将旧关闭账号迁移为自动记忆，并提升 revision；原账号、凭据、来源和测试记录保留。产品 API 仅删除/反馈，拒绝开关/手动改写。隔离评测仍支持开关/纠正情境。开发和验收没有启动该迁移操作现有部署。
- 评测台：默认单环节测试，覆盖理解、检索、回复、记忆、摘要、首页、判定；当前版本/历史版本/临时草稿均保留准确输入、实际传输、提示词全文/哈希、公开工具证据、调用状态与历史。当前版本中途被他人切换会明确拒绝。自动检查按环节实际约束说明，质量始终待人工判断。
- 整体测试：保留真实 SDK 的连续交互、评测集、批量 A/B、系统判定、人工复核、版本组合与独立启用。单环节是固定上游输入的受控实验，不改变实际生产调用结构。
- 静态预览：同一根产品代码按白名单构建，真实 API 永久禁用，保留虚构演示和素材/指南许可。部署 Nginx 验证根 HTML、模块、CSS、运行配置、视频的真实响应头；开发代理限额与后端一致。
