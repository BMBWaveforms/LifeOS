# 提示词维护

| 文件 | 使用阶段 | 修改范围 |
|---|---|---|
| chat.md | 个性化问答 Agent | 问题理解、澄清、选择指南、结果状态 |
| summary.md | 每轮答复之后 | 摘要、用户状态、咨询指南、进展判断 |
| home.md | 首页回访 | 从有效问题中选择需回访的记录 |
| tools.json | 问答工具声明 | 工具描述和参数定义；工具名仍须是两个只读工具 |

模型直接接收对应 Markdown 全文，不需要去代码里修改系统提示词。每次调用读取文件；本地修改会在后续调用生效，Docker 中此目录只读挂载。API 返回本次使用的系统提示词 SHA-256，便于复现。

输出 JSON 格式和校验规则见 `../docs/架构与接口.md`；修改字段时须同步后端校验及测试。内容边界见 `../skills/guide-only.md`。提示词描述期望行为，后端负责权限、回读记录、版本、来源和写入校验。

不要把密钥或个人完整聊天放进提示词。用户问题、历史摘要、指南正文均作为低优先级数据输入。
